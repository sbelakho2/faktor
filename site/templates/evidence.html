The completion chain

Four questions before the finish.

  1. 01

    Did the required criteria pass?

    Pass requires present, passing required results. A missing required check stays Pending; an observed failure is Fail. An empty set is not a complete proof of a verified change.

  2. 02

    What claim did the evidence answer?

    Keep the named claim bound to the candidate snapshot. Unavailable evidence means no verdict; a refusal is a separate outcome.

  3. 03

    Is this the state that will land?

    Expose verified and landed identities. A different landed snapshot cannot use a result for another candidate as its evidence basis; a result for earlier code cannot certify later integration.

  4. 04

    Did the requested actions succeed?

    Local changes, commit, push and native pull request carry distinct outcomes. Missing SCM configuration, skipped work and unsuccessful steps stay visible.
