Choose the host.

VS Code opens Faktor through its command and webview. JetBrains uses a right-anchored tool window. Keep binary discovery, daemon transport and project binding understandable before the first run.

The expanded design introduces a consistent Work / Inspect / History structure while retaining host-specific behavior. The current VS Code History surface and common finish selector are proposed additions; JetBrains already has the three top-level views.

Give the task conditions.

Record the goal, acceptance criteria, invariants, risks and requested finish action. An isolated candidate separates editing from integration. Context and permissions stay scoped to the task.

Completion has a chain.

Required acceptance, claim evidence, candidate identity, integration and requested finish actions are distinct. Missing data stays visible. An empty required-check set can pass without establishing a verified change.
