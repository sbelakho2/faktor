## Adversarial / negative coverage executed

- Auth: every native surface without the bearer returned 401; all live
  probes used the real password.
- Limits: `events`/`messages` reject `limit=0` and `limit>200`; config
  rejects unknown keys/values; attachment filename traversal is refused
  with a typed 400; unknown route → 404; malformed bodies → 400.
- Trust: unrecorded executable, recorded checksum match, tampered copy
  mismatch, and query-path encoding were exercised (`G01/F009-*`).
- Crash: SIGKILL during a turn, restart on the same data dir, ownerless
  permission expiry, same-op resume (`G01/F020-*`).
- Concurrency: two sessions and two children on one local runtime
  (`G03/F077-*`, `G04/F092-*`).
- Secrets: planted fake provider secret never appeared in journal,
  snapshot, search values or export; only the credential handle was listed.
- Idempotence: prompt key replay and task-start replay (`G03/F063-*`,
  `G04/F102-*`).
- Policy: Ask preset mutating start 409; loopback/private-LAN endpoint
  refusals (`G04/F086-refusal.json`, `G02/F040-*`).
