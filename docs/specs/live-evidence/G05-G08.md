## Defects found and fixed

| Defect | Fix | Files / regression test |
|---|---|---|
| Instruction glob semantics | `src/**/*.rs` did not match `src/lib.rs`; `**/` is now zero-or-more complete segments with O(pattern*text) matching. | `crates/foundation/src/instructions.rs`; regression `instructions::tests::precedence_conflicts_and_activation_are_exact_and_deterministic`. |
| Concurrent sessions on one workspace | Two live shadows made workspace-scoped instruction resolution fail. Resolution is now session-scoped (own shadow/root), while the workspace-only probe stays conservative. | `crates/instructions/src/lib.rs`, `crates/cli/src/daemon/builder.rs`, `crates/agent/src/runtime/turn/state.rs`, `crates/agent/src/runtime/retrieval.rs`, `crates/server/src/native/instructions.rs`; regression `session_scoped_root_resolution_is_unambiguous_with_two_live_shadows`. |

Creation and fork now adopt the workspace owner worktree. | `crates/session/src/manager.rs`, `crates/server/src/native/session.rs`; regressions `fork_session_adopts_the_workspace_owner_worktree`, `create_session_binds_the_workspace_owner_worktree`. |
| Mid-turn fork corruption | Forking a live session could copy duplicate seqs (UNIQUE) and a torn history; fork now refuses typed before copying. | `crates/session/src/manager.rs`; regression `fork_refuses_a_mid_turn_session_before_copying_any_message`. |
