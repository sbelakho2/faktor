## Evidence artifact conventions

- One evidence directory per feature: `target/live-matrix/<group>/<feature-id>/`.
- Capture the exact command/route, stdout/stderr or JSON response, exit status, data-dir/repo/worktree path, model id and Ollama tag, and the relevant durable row/artifact digest.
- Capture the negative case named by the acceptance/invariant where one exists; a green path alone is not evidence.
- Never place credential values in evidence; record the env/config NAME and present/absent state only.
